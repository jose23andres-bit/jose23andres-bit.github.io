Política de privacidad

Última actualización: 19 de noviembre de 2026.

La aplicación "gtadoge" es una herramienta de uso exclusivo del titular del canal de YouTube @gtadoge. Sirve para publicar en ese canal los vídeos que el propio titular produce. No tiene usuarios externos.

Datos a los que accede

Con la autorización del titular, la aplicación usa los Servicios de API de YouTube para subir vídeos, miniaturas y subtítulos al canal @gtadoge. No lee, recopila ni almacena datos de otros usuarios, espectadores o suscriptores.

Almacenamiento

El token de autorización se guarda cifrado como secreto en un repositorio privado de GitHub del titular. No se comparte con terceros. No se usan cookies.

Servicios de terceros

La aplicación usa los Servicios de API de YouTube. Al usarla se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Revocar el acceso

El acceso se puede retirar en cualquier momento desde la página de permisos de seguridad de Google.
